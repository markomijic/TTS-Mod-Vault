# Translators

Thank you to everyone who translated TTS Mod Vault. The About tab in the app
shows this list.

To be credited, add one line per language to the list below, in the form
`- <locale tag>: Name, Name`, for example `- de: Jane Doe, John Roe`. The tag
is the one of the `app_<locale>.arb` file (`de`, `pt-BR`). Everything that is
not such a line is ignored by the app. See
[docs/translating.md](docs/translating.md) for how to translate.
