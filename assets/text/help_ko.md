# 시작하기

TTS Mod Vault는 Tabletop Simulator의 `Mods` 및 `Saves` 폴더를 읽어 모든 모드, 저장 게임, 저장된 오브젝트와 그 에셋 파일의 상태를 보여 주고, 누락된 파일을 다운로드하고 `.ttsmod` 백업을 만들고 복원할 수 있게 해 줍니다.

- 설정 → 폴더에서 폴더를 지정하세요. 백업 폴더는 선택 사항이지만, 실행할 때마다 백업 상태를 기억하려면 필요합니다.
- 라이브러리는 시작할 때 색인됩니다. 앱 밖에서 파일을 바꾼 뒤에는 사이드바의 새로 고침을 누르세요. "Vault 캐시 지우기"는 모든 JSON 파일을 다시 읽습니다.
- 모드, 저장 게임, 저장된 오브젝트, 백업은 목록 위의 탭입니다. 저장된 오브젝트는 설정 → 기능에서 켜면, 백업은 백업 폴더를 지정하면 나타납니다.

# 라이브러리

- 모드를 클릭하면 에셋과 작업이 표시됩니다
- 모드를 마우스 오른쪽 버튼으로 클릭하면 더 많은 작업(다운로드, 백업, 폴더 열기, 이름 바꾸기, 삭제 등)이 표시됩니다
- Ctrl+클릭(macOS에서는 Cmd+클릭)으로 여러 모드를 선택해 일괄 작업을 할 수 있습니다
- 모드의 백업 아이콘에 마우스를 올리면 백업 날짜와 에셋 수가 표시됩니다
- 종류 선택기에 마우스를 올리면 모드, 저장 게임, 저장된 오브젝트가 각각 몇 개인지 표시됩니다
- 도구 모음으로 검색, 정렬, 필터를 할 수 있으며, 일괄 작업은 검색어와 필터를 따릅니다
- 키보드: Ctrl+F 검색, F5 새로 고침, Esc 선택 해제, Delete 확인 후 선택한 모드 삭제

# 선택한 모드

오른쪽 패널에는 선택한 모드의 에셋이 종류별로 묶여 표시됩니다. URL 색상:

- 빨간색: 에셋 파일이 누락됨
- 초록색: 에셋 파일이 다운로드됨
- 주황색: URL 확인에서 유효하지 않은 URL로 표시됨
- 강조: 마지막으로 클릭한 URL

작업:

- URL을 왼쪽 또는 오른쪽 버튼으로 클릭하면 옵션(열기, 복사, 다운로드, 바꾸기, 파일 삭제)이 표시됩니다
- PDF 썸네일을 더블 클릭하면 파일이 열립니다
- 모두 다운로드: 누락된 에셋 파일을 모두 다운로드합니다. 그 뒤에도 누락된 파일은 확인을 거쳐, "다운로드 확인 결과" 대화 상자에 연결할 수 없는 도메인과 작동하지 않는 URL이 표시됩니다. 설정 → 네트워크 → 다운로드 후 누락된 파일 확인에서 끌 수 있습니다
- 카드의 "3개 누락, 2개 유효하지 않음": 파일 3개가 누락되었고, URL 확인 결과 그중 2개의 URL이 작동하지 않아 다운로드할 수 없다는 뜻입니다
- 백업: 다운로드한 에셋 파일로 백업을 만듭니다
- 오디오 에셋은 설정 → 기능에서 전체적으로 제외할 수 있고, 모드별로는 모드의 컨텍스트 메뉴에서 바꿀 수 있습니다

# 백업

- 백업은 모드 JSON, 이미지, 다운로드한 모든 에셋 파일이 들어 있는 `.ttsmod` 파일입니다.
- 백업 상태는 백업과 모드를 비교합니다: 최신, 오래됨(백업 후 JSON이 바뀜), 에셋 수 불일치.
- 사이드바의 백업 가져오기로 파일을 Mods 폴더에 복원합니다. JSON 가져오기는 JSON 파일로 모드를 추가합니다.
- 일괄 백업은 건너뛰기, 바꾸기, 오래된 경우 바꾸기를 지원하며, 백업 후 모드의 파일을 삭제할 수도 있습니다.

# URL 업데이트

URL 업데이트 기능은 URL의 앞부분, 또는 URL 전체를 "예전 접두사"에서 "새 접두사"로 바꿉니다.

예전 접두사 여러 개를 `|` (세로 막대) 기호로 구분해 입력할 수 있습니다. 설정 → URL 업데이트 프리셋에서 프리셋을 만들면 URL 업데이트 대화 상자에 표시됩니다.

예전 접두사 하나 사용:

- 예전 접두사: `http://pastebin.com/raw.php?i=`
- 새 접두사: `https://pastebin.com/raw/`

모드에 `http://pastebin.com/raw.php?i=1234`와 `http://pastebin.com/raw.php?i=example`이 있으면 `https://pastebin.com/raw/1234`와 `https://pastebin.com/raw/example`로 바뀝니다.

예전 접두사 여러 개 사용:

- 예전 접두사: `http://pastebin.com/raw.php?i=|http://pastebin.com/raw/|http://pastebin.com/`
- 새 접두사: `https://pastebin.com/raw/`

모드에 `http://pastebin.com/raw.php?i=abcd`, `http://pastebin.com/raw/5678`, `http://pastebin.com/example2`가 있으면 `https://pastebin.com/raw/abcd`, `https://pastebin.com/raw/5678`, `https://pastebin.com/raw/example2`로 바뀝니다.

# 창작마당

- 사이드바에서 Steam 창작마당 ID나 URL로 모드를 다운로드합니다. ID 여러 개를 한 번에 입력할 수 있습니다.
- 창작마당에서 업데이트는 이미 있는 모드의 JSON을 다시 다운로드합니다. 강제 옵션은 더 새로운 로컬 파일도 덮어씁니다.

# 문제 해결

- 목록 아래의 로그 패널은 모든 작업과 실패를 기록합니다. 펼쳐서 수준과 출처로 필터하고, 검색하고, 항목을 복사하거나 지울 수 있습니다. 항목을 클릭하면 해당 모드가 선택됩니다.
- 로그 파일 `vault.log`는 데이터베이스 옆에 있습니다. 로그 패널 머리글이나 정보 탭에서 열 수 있으며, 버그 신고 시 첨부해 주세요.
- 폴더를 바꾼 뒤 아무것도 보이지 않나요? 새로 고침을 누르세요. 그래도 안 되면 설정 → 폴더의 폴더 경로와 제외할 하위 폴더를 확인하세요.
- 한꺼번에 많이 다운로드할 때 정상 URL이 실패하나요? 설정 → 네트워크에서 동시 다운로드 수를 낮추세요.
- URL 확인과 다운로드 후 확인은 먼저 각 도메인에 연결할 수 있는지 시험합니다. 연결할 수 없는 도메인(다운되었거나 네트워크에서 차단됨)의 URL은 유효하지 않다고 표시하지 않으며, 그런 도메인이 있는 URL 확인 결과는 저장하지 않습니다. 설정 → 네트워크 → 모든 모드 및 저장 게임 도메인 확인으로 모드와 저장 게임이 쓰는 모든 도메인을 시험할 수 있습니다.
