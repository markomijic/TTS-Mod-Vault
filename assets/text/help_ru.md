# Начало работы

TTS Mod Vault читает папки `Mods` и `Saves` Tabletop Simulator, показывает каждый мод, сохранение и сохранённый объект вместе с состоянием их файлов ресурсов и позволяет скачивать недостающие файлы, создавать резервные копии `.ttsmod` и восстанавливать их.

- Укажите папки в Настройки → Папки. Папка резервных копий необязательна, но без неё состояние копий не запоминается между запусками.
- Библиотека индексируется при запуске; после изменения файлов вне приложения нажмите Обновить на боковой панели. «Очистить кэш Vault» перечитывает все JSON-файлы.
- Моды, Сохранения, Сохранённые объекты и Копии — это вкладки над списком. Сохранённые объекты появляются, если включены в Настройки → Функции, а Копии — если задана папка резервных копий.

# Библиотека

- Щёлкните по моду, чтобы увидеть его ресурсы и действия
- Щёлкните по моду правой кнопкой, чтобы открыть другие действия (скачать, создать копию, открыть папку, переименовать, удалить, ...)
- Ctrl+щелчок (Cmd+щелчок в macOS) — выбрать несколько модов для массовых действий
- Наведите курсор на значок копии мода, чтобы увидеть дату копии и число ресурсов
- Наведите курсор на переключатель типов, чтобы увидеть, сколько всего модов, сохранений и сохранённых объектов
- Ищите, сортируйте и фильтруйте с помощью панели инструментов; массовые действия учитывают текст поиска и фильтры
- Клавиатура: Ctrl+F — поиск, F5 — обновить, Esc — снять выделение, Delete — удалить выбранный мод после подтверждения

# Выбранный мод

Правая панель показывает ресурсы выбранного мода, сгруппированные по типу. Цвета URL:

- Красный: файл ресурса отсутствует
- Зелёный: файл ресурса скачан
- Оранжевый: проверка URL отметила его как недействительный
- Выделенный: URL, по которому вы щёлкнули последним

Действия:

- Щёлкните по URL левой или правой кнопкой, чтобы открыть меню (открыть, копировать, скачать, заменить, удалить файл)
- Дважды щёлкните по миниатюре PDF, чтобы открыть файл
- Скачать всё: скачивает все недостающие файлы ресурсов. Файлы, которые после этого всё ещё отсутствуют, проверяются: окно «Результаты проверки после скачивания» показывает недоступные домены и неработающие URL. Это можно отключить в Настройки → Сеть → Проверять недостающие файлы после скачивания
- «Нет: 3, недействительных: 2» на карточке: не хватает 3 файлов, и проверка URL показала, что 2 из их URL не работают, поэтому эти файлы скачать нельзя
- Резервная копия: создаёт копию из скачанных файлов ресурсов
- Аудиоресурсы можно исключить для всех модов в Настройки → Функции и переопределить для отдельного мода через его контекстное меню

# Резервные копии

- Резервные копии — это архивы `.ttsmod` с JSON мода, его изображением и всеми скачанными файлами ресурсов.
- Состояние копии сравнивает её с модом: актуальна, устарела (JSON изменился после создания копии) или не совпадает число ресурсов.
- «Импорт копий» на боковой панели восстанавливает архивы в папку Mods. «Импорт JSON» добавляет мод из JSON-файла.
- Массовое создание копий умеет пропускать, заменять и заменять устаревшие копии, а затем при желании удалять файлы мода.

# Обновление URL

Функция «Обновить URL» заменяет начало URL, или даже URL целиком, из поля «Старый префикс» на «Новый префикс».

Можно указать несколько старых префиксов, разделив их символом `|` (вертикальная черта). В Настройки → Шаблоны обновления URL можно создать шаблоны, которые затем предлагаются в окне «Обновить URL».

Один старый префикс:

- Старый префикс: `http://pastebin.com/raw.php?i=`
- Новый префикс: `https://pastebin.com/raw/`

Если в моде есть `http://pastebin.com/raw.php?i=1234` и `http://pastebin.com/raw.php?i=example`, они станут `https://pastebin.com/raw/1234` и `https://pastebin.com/raw/example`.

Несколько старых префиксов:

- Старые префиксы: `http://pastebin.com/raw.php?i=|http://pastebin.com/raw/|http://pastebin.com/`
- Новый префикс: `https://pastebin.com/raw/`

Если в моде есть `http://pastebin.com/raw.php?i=abcd`, `http://pastebin.com/raw/5678` и `http://pastebin.com/example2`, они станут `https://pastebin.com/raw/abcd`, `https://pastebin.com/raw/5678` и `https://pastebin.com/raw/example2`.

# Мастерская

- Скачивайте моды из Мастерской Steam по ID или ссылке с боковой панели; можно ввести сразу несколько ID.
- «Обновить из Мастерской» заново скачивает JSON уже существующего мода. Принудительное обновление перезаписывает более новый локальный файл.

# Решение проблем

- Панель журнала под списком записывает каждую операцию и её ошибки; разверните её, чтобы фильтровать по уровню и источнику, искать, копировать записи или очистить журнал. Щёлкните по записи, чтобы выбрать её мод.
- Файл журнала `vault.log` лежит рядом с базой данных. Откройте его из заголовка панели журнала или на вкладке «О программе»; прикладывайте его к сообщениям об ошибках.
- После смены папки ничего не появилось? Нажмите Обновить. Всё равно пусто? Проверьте пути к папкам в Настройки → Папки и исключённые подпапки.
- Рабочие URL не скачиваются, когда загрузок много? Уменьшите число одновременных загрузок в Настройки → Сеть.
- Проверки URL и проверка после скачивания сначала выясняют, доступен ли каждый домен. URL на недоступном домене (он не работает или заблокирован в вашей сети) не отмечаются как недействительные, а проверка URL с таким доменом не сохраняется. Настройки → Сеть → Проверить все домены модов и сохранений проверяет каждый домен, который используют ваши моды и сохранения.
