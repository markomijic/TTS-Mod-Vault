# 入门

TTS Mod Vault 会读取 Tabletop Simulator 的 `Mods` 和 `Saves` 文件夹，显示每个模组、存档和保存的物件及其资源文件的状态，并让你下载缺失的文件、创建 `.ttsmod` 备份以及恢复备份。

- 在 设置 → 文件夹 中设置文件夹。备份文件夹是可选的，但若要在每次启动之间记住备份状态，就需要设置它。
- 库会在启动时建立索引；在应用外更改文件后，请点击侧边栏中的“刷新”。“清除 Vault 缓存”会重新读取所有 JSON 文件。
- 模组、存档、保存的物件和备份是列表上方的标签。在 设置 → 功能 中启用后会显示保存的物件，设置了备份文件夹后会显示备份。

# 库

- 左键单击模组可查看其资源和操作
- 右键单击模组可查看更多操作（下载、备份、打开文件夹、重命名、删除等）
- Ctrl+单击（macOS 上为 Cmd+单击）可选择多个模组进行批量操作
- 将鼠标悬停在模组的备份图标上可查看备份日期和资源数量
- 将鼠标悬停在类型选择器上可查看模组、存档和保存的物件各有多少
- 使用工具栏搜索、排序和筛选；批量操作遵循搜索文本和筛选条件
- 键盘：Ctrl+F 聚焦搜索，F5 刷新，Esc 清除选择，Delete 在确认后删除所选模组

# 所选模组

右侧面板按类型分组列出所选模组的资源。URL 颜色：

- 红色：资源文件缺失
- 绿色：资源文件已下载
- 橙色：URL 检查将该 URL 标记为无效
- 高亮：你最后单击的 URL

操作：

- 左键或右键单击 URL 可查看选项（打开、复制、下载、替换、删除文件）
- 双击 PDF 缩略图可打开文件
- 全部下载：下载所有缺失的资源文件。之后仍缺失的文件会被检查：“下载检查结果”对话框会列出无法访问的域名和失效的 URL。可在 设置 → 网络 → 下载后检查缺失的文件 中关闭此功能
- 卡片上的“缺失 3，无效 2”：缺失 3 个文件，且 URL 检查发现其中 2 个 URL 已失效，因此这些文件无法下载
- 备份：用已下载的资源文件创建备份
- 音频资源可在 设置 → 功能 中全局排除，也可在模组的右键菜单中为单个模组单独设置

# 备份

- 备份是 `.ttsmod` 存档，包含模组 JSON、其图片以及所有已下载的资源文件。
- 备份状态会将备份与模组进行比较：最新、已过期（备份后 JSON 有变化）或资源数量不符。
- 使用侧边栏中的“导入备份”将存档恢复到 Mods 文件夹。“导入 JSON”可从 JSON 文件添加模组。
- 批量备份支持跳过、替换和过期时替换，并可选择在备份后删除模组的文件。

# 更新 URL

“更新 URL”功能会把 URL 的开头部分，甚至整个 URL，从“旧前缀”替换为“新前缀”。

可以用 `|`（竖线）分隔输入多个旧前缀。在 设置 → URL 更新预设 中可以创建预设，之后会出现在“更新 URL”对话框中。

使用单个旧前缀：

- 旧前缀：`http://pastebin.com/raw.php?i=`
- 新前缀：`https://pastebin.com/raw/`

如果你的模组包含 `http://pastebin.com/raw.php?i=1234` 和 `http://pastebin.com/raw.php?i=example`，它们将更新为 `https://pastebin.com/raw/1234` 和 `https://pastebin.com/raw/example`。

使用多个旧前缀：

- 旧前缀：`http://pastebin.com/raw.php?i=|http://pastebin.com/raw/|http://pastebin.com/`
- 新前缀：`https://pastebin.com/raw/`

如果你的模组包含 `http://pastebin.com/raw.php?i=abcd`、`http://pastebin.com/raw/5678` 和 `http://pastebin.com/example2`，它们将更新为 `https://pastebin.com/raw/abcd`、`https://pastebin.com/raw/5678` 和 `https://pastebin.com/raw/example2`。

# 创意工坊

- 从侧边栏按 Steam 创意工坊 ID 或 URL 下载模组；可以一次输入多个 ID。
- “从创意工坊更新”会重新下载已存在模组的 JSON。强制选项会覆盖较新的本地文件。

# 故障排除

- 列表下方的日志面板会记录每个操作及其失败情况；展开后可按级别和来源筛选、搜索、复制条目或清空日志。单击条目可选中其模组。
- 日志文件 `vault.log` 位于数据库旁边。可从日志面板标题栏或“关于”标签打开；提交错误报告时请附上它。
- 更改文件夹后什么都没显示？点击“刷新”。仍然没有？检查 设置 → 文件夹 中的文件夹路径和排除的子文件夹。
- 同时下载很多文件时，有效的 URL 下载失败？在 设置 → 网络 中降低同时下载数。
- URL 检查和下载后的检查会先测试每个域名能否访问。无法访问的域名（宕机或在你的网络中被屏蔽）上的 URL 不会被标记为无效，包含此类域名的 URL 检查结果也不会保存。设置 → 网络 → 检查所有模组和存档的域名 会测试你的模组和存档使用的每个域名。
